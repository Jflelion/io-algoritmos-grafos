# Investigación de Operaciones: Algoritmos de grafos

Proyectos de la materia de Investigación de Operaciones, Ingeniería de Sistemas. Cada uno implementa un algoritmo clásico de grafos con una interfaz web hecha en HTML, CSS y JavaScript.

## Proyectos

| Proyecto | Algoritmo | Qué resuelve |
|----------|-----------|--------------|

| [AEM](./AEM) | Árbol de Expansión Mínima | Conecta todos los nodos de un grafo con el menor costo total |
| [Dijkstra](./Dijkstra) | Dijkstra | Ruta más corta desde un nodo origen hacia los demás |
| [Floyd](./Floyd) | Floyd-Warshall | Rutas más cortas entre todos los pares de nodos |

## Cómo ejecutarlos

No necesitas instalar nada.

1. Descarga o clona el repositorio:

```bash
   git clone https://github.com/Jflelion/io-algoritmos-grafos.git

```

2.Entra a la carpeta del proyecto que quieras probar.

3.Abre su `index.html` en el navegador.
