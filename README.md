# Investigación de Operaciones

Proyectos de la materia de Investigación de Operaciones, hechos con HTML, CSS y JavaScript.

## Proyectos

- **AEM**: árbol de expansión mínima.
- **Dijkstra**: ruta más corta desde un nodo al resto del grafo.
- **Floyd**: rutas más cortas entre todos los pares de nodos.

## Cómo ejecutarlos

Entra a la carpeta del proyecto que quieras probar y abre su `index.html` en el navegador. No necesitas instalar nada.
